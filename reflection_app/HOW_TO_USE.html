⚙️ One-Time Setup (Before First Use)

Step 1 — Create the Database Tables

Run this once on the SQL Server before launching the application for the first time.
1
Open SSMS (SQL Server Management Studio) and connect to TNBIMSPROD\TNBIMSPROD
2
Open the file create_tables.sql from this folder
3
Click Execute (F5) — you should see:
Table dbo.reflection_submissions created.
Table dbo.competency_responses created.
Setup complete. Both tables are ready.
If it says "already exists — skipped", that is also fine — the tables already exist.

Step 2 — Install Python Dependencies

Run the following command in your terminal / command prompt inside the reflection_app folder:

pip install flask pandas openpyxl reportlab pyodbc

Or use the requirements file if provided:

pip install -r requirements.txt
ODBC Driver 17 for SQL Server must also be installed on the machine that will run the app. Download from Microsoft: Microsoft ODBC Driver 17 for SQL Server

Step 3 — Place the Data Files

Make sure both Excel files exist in the data/ subfolder:

FileContains
data/employee_data.xlsxAll employee records — EmpID, Name, Role, Role Function, Team Leader, Division
data/competencies.xlsxCompetency framework — one sheet per Role Function, columns per Band level

🚀 Running the Application

1
Open a terminal / command prompt
2
Navigate to the reflection_app folder:
cd path\to\reflection_app
3
Run the app:
python app.py
4
Open a browser and go to:
http://localhost:5000
Or share http://<your-machine-ip>:5000 with employees on the same network.
The app loads all employee and competency data at startup. The first page load may take 2–3 seconds.

📝 How Employees Use the Form

Page 1 — Select Employee & Band

The employee:

  • Types their name or Employee ID in the search box to filter the list
  • Clicks their name in the dropdown — their details (Role, Role Function, Team Leader, Division) appear below automatically
  • Selects their Band level (FT / FMT / OMT / BMT / SMT)
  • Clicks Next → General Questions
BandFull Name
FTFront-line Team
FMTFront-line Management Team
OMTOperations Management Team
BMTBusiness Management Team
SMTSenior Management Team

Page 2 — General Reflection Questions (Part A)

9 open-ended questions about the employee's contributions, learnings, challenges, and career direction. These are the same for all employees.

  • Questions 1–6, 8, 9 are free-text areas
  • Question 7 is a multi-select checkbox (career direction options)

Click Next → Competency Assessment to continue.

Page 3 — Competency Self-Assessment (Part B)

Competencies are loaded automatically based on the employee's Role Function and selected Band.

For each competency the employee:

  • Reads the Expected behaviour at their Band level (shown in blue)
  • Drags the rating slider from 0 to 10
  • Writes a self-reflection with specific examples

Click Preview Entries → when done.

Page 4 — Preview & Submit

The employee reviews all their answers — Part A and Part B — before submitting.

  • Click ✏️ Edit Answers to go back and make changes
  • Click ✅ Submit & Save to save to the database

After successful submission:

  • A confirmation screen shows the Submission ID
  • Click 📥 Download as PDF to download the complete reflection form
  • A reminder is shown to send the PDF to the Team Leader before the deadline

🔧 Troubleshooting

ProblemLikely CauseFix
App won't start — ModuleNotFoundError Missing Python package Run pip install flask pandas openpyxl reportlab pyodbc
No employees in dropdown employee_data.xlsx not found Check that the file is in the data/ folder
No competencies shown Role Function not mapped in data_loader.py Check ROLE_FUNCTION_SHEET_MAP in data_loader.py and ensure the employee's Role Function is listed
Submit fails — DB error ODBC driver not installed, or network can't reach SQL Server Install ODBC Driver 17 for SQL Server; ensure app server can reach TNBIMSPROD
PDF download is blank / missing data Session expired or employee went directly to download URL Complete the full form flow from Page 1
Port 5000 already in use Another process using port 5000 Change the port in app.py: app.run(port=5001)

🌐 Deploying for the Whole Office

To let all employees access the form from their own computers:

1
Run the app on a machine that is always on (a server or a dedicated PC on the office network)
2
Find that machine's IP address: ipconfig on Windows → look for IPv4 Address (e.g. 192.168.1.50)
3
Share the URL with employees: http://192.168.1.50:5000
For production use, consider running behind IIS or Gunicorn + nginx with a proper domain name. Contact your IT team for assistance.
